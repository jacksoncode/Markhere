### 任务清单

#### 🔴 P0 - 高优先级（必须完成）
1. **Windows 平台监控增强** (2天)
   - 问题：防止崩溃问题回归
   - 方案：Sentry + 系统资源监控 + E2E 测试
   - 目标：崩溃率 < 0.1%

2. **大文件性能优化** (3天)
   - 问题：>5MB 文件加载卡顿
   - 方案：分块加载 + 流式处理 + 进度反馈
   - 目标：10MB < 4s（提升 50%）

#### 🟡 P1 - 中优先级（强烈建议）
3. **协作同步延迟优化** (2天)
   - 方案：批处理 + Y.js 优化
   - 目标：P95 延迟 < 500ms

4. **Mermaid 渲染优化** (2.5天)
   - 方案：Web Worker + 按需加载
   - 目标：复杂图表 < 400ms（提升 50%）

5. **Linux 图片粘贴修复** (2天)
   - 方案：多策略回退 + Tauri 原生
   - 目标：成功率 > 95%

#### 🟢 P2 - 低优先级（体验改善）
6. **暗色主题对比度** (1.5天)
   - 方案：WCAG AA 合规
   - 目标：所有元素达标

7. **移动端响应式** (5天)
   - 方案：触控优化 + 移动特性
   - 目标：iOS/Android 完整支持
