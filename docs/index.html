📝 文本格式化

操作 快捷键 效果
加粗 Ctrl/Cmd + B 粗体文本
斜体 Ctrl/Cmd + I 斜体文本
下划线 Ctrl/Cmd + U 下划线文本
代码 Ctrl/Cmd + E inline code

🤖 AI助手使用

1

打开设置 > AI助手

2

选择供应商（DeepSeek、GLM、Kimi等）

3

输入API Key，自动获取可用模型

4

选中文本，使用快捷键触发功能

功能 快捷键
智能补全 Alt + Space
润色优化 Ctrl/Cmd + Alt + R
翻译 Ctrl/Cmd + Alt + T
摘要总结 Ctrl/Cmd + Alt + S

🔗 双向链接与知识图谱

[[项目计划]] - 链接到"项目计划"文档
[[会议纪要|上周会议]] - 自定义显示文本

使用 Ctrl/Cmd + Shift + G 打开知识图谱，可视化所有链接关系

📤 导出文档

  • PDF - 打印、分享，支持自定义页面大小
  • Word (DOCX) - Office协作，格式完整保留
  • HTML - 网页发布，响应式输出
  • EPUB - 电子书格式，适合出版
  • Markdown - 源码导出，版本控制
